DIC-1 — Personal Page
🎯 作業目標
使用 Antigravity + GitHub + GitHub Pages，建立並發布自己的 Personal Page 個人網站。

這次作業的重點不是把老師的網站完全複製，而是學會完整的網站開發流程：

Idea → AI Build → Test → GitHub → Publish

完成後，你會擁有一個真正可以透過 Internet 開啟的個人網站。

📌 Basic Requirements
你的 Personal Page 至少必須包含以下 5 項內容。

👤 1. Profile
介紹你自己，例如：

姓名

個人照片或 Avatar

科系 / 專長

簡短自我介紹

🛠 2. Skills
至少列出 3 項技能。

例如：

Python

C / C++

Machine Learning

AI

IoT

Web Development

Data Analysis

🚀 3. Projects
至少介紹 1 個自己的作品或專案。

可以包含：

Project Name

Project Description

使用技術

GitHub Link

如果目前沒有作品，也可以放這學期預計完成的 Project。

🕐 4. Live Clock
使用 JavaScript 製作即時時鐘。

至少顯示：

HH : MM : SS

時間必須會自動更新。

🎨 5. Personal Design
不要直接複製老師的網頁。

請利用 Antigravity 與 AI 修改成自己的風格，例如：

顏色

字型

Background

Layout

Cards

Animation

個人照片

自己喜歡的 Theme

🤖 How to Do
Step 1 — Create GitHub Repository
在 GitHub 建立新的 Repository。

建議名稱：

DIC1_PersonalPage

或：

YOUR_NAME_PersonalPage

Step 2 — Connect Antigravity
使用 Antigravity IDE 開啟或連接你的 GitHub Repository。

確認 AI Agent 可以讀取並修改專案。

Step 3 — Tell AI What You Want
不要急著自己從零開始寫所有 HTML / CSS / JavaScript。

先告訴 AI：

Create a modern personal page for me.
Include my profile, skills, projects and a real-time JavaScript clock.
Make the design responsive and suitable for GitHub Pages.

接著再逐步告訴 AI 你想修改的地方。

Step 4 — Build & Test
使用 Antigravity 協助建立：

index.html
style.css
app.js
在瀏覽器測試：

網頁是否正常顯示

Live Clock 是否會動

手機與電腦版面是否正常

Link 是否可以點擊

個人資料是否正確

Step 5 — Push to GitHub
完成後將程式碼：

Commit → Push → GitHub

確認 Repository 中可以看到你的：

index.html
style.css
app.js
README.md
Step 6 — Publish with GitHub Pages
在 GitHub Repository：

Settings → Pages

設定：

Branch: main
Folder: /root
等待 GitHub Pages 完成部署。

成功後，你會得到類似：

https://YOUR_NAME.github.io/DIC1_PersonalPage/
的網址。
